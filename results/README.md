# Frozen evidence snapshot

This directory is a byte-for-byte copy of the Phase 2D.1 final evidence tables and source-artifact manifest. `tables/` contains five manuscript result tables and ten figure-source tables. The corresponding PNG, PDF, and SVG figures are in `../figures/`.

`FROZEN_RESULTS_MANIFEST.json` identifies and hashes the scientific source artifacts from which the final evidence was generated. Those large or redistribution-sensitive source artifacts are not themselves included here. The manifest's `generated_utc` records evidence-package generation time and is not a repository release date.
